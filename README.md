## 🚀 Featured Projects

### 🆘 [Sahaya — Disaster Management & Emergency Response App](https://github.com/gomesdisha/Sahaya)
> Android · Java · Firebase · Gemini API · Google Maps API

A multi-role Android application for real-time disaster reporting, SOS alerts, and volunteer–authority coordination. Includes an AI-powered chatbot (Gemini API) for emergency guidance, live GPS tracking, Firebase Cloud Messaging, and an admin dashboard managing incidents across 3 user roles.

---

### 🥗 [NutriTracker — Child Nutrition Monitoring System](https://github.com/gomesdisha/NutriTracker)
> MERN Stack · Chart.js · JWT · REST APIs

Full-stack web app for centralized child growth monitoring across Anganwadi centers. Implements WHO-standard malnutrition detection (height-for-age, weight-for-age), role-based JWT auth, and interactive Chart.js dashboards for real-time analytics.

---

### 🔐 [AquaGuard — Digital Watermarking & Copyright Protection](https://github.com/gomesdisha/Aquagard--A-digital-watermarking-and-copyright-protection-system)
> Python · React.js · MongoDB · AES-256 · LSB Steganography

Cybersecurity platform for invisible watermarking of images and PDFs using AES-256 encryption, SHA-3 hashing, and LSB steganography. Includes secure authentication and MongoDB-backed audit trails.
